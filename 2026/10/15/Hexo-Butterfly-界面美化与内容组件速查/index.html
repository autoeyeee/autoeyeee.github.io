界面美化与内容组件速查

发表于2026-10-15|更新于2026-10-15|教程Hexo
|浏览量:

界面美化 · 说明书

自定义组件

配色 / 字体 / 排版 / 内容组件 —— 全在 source/self/ 下，随时能改、随时能删

这篇是写给自己的说明书：这次给博客做了一次整体美化，换了配色与中文字体、重做了卡片和正文排版，还加了一套内容组件。以后写项目介绍，不用再纠结「能不能做得像 PPT」，直接挑组件拼就行。

写组件时的一条硬规矩：组件内部的标题一律用 <p class="xxx-title">，不要用 <h3> / <h4>。
Hexo 的目录（TOC）会把它们当成章节抓进去，但这类手写标签拿不到锚点 id，结果是目录里多出一堆点不动的空条目，
还会让主题的「目录高亮」脚本报错。正文自己的章节标题照旧用 ## / ### 就好。

这次改了什么

4个样式层文件
16个内容组件
2套配色（明 / 暗）
0个外部 CDN 依赖

配色重做

主色从默认的天蓝换成 indigo → violet → cyan 的冷色系，中性色改用偏冷的 slate 阶，明暗两套模式共用同一套令牌。

中文正文字体

正文换成霞鹜文楷屏幕阅读版（GB 字形），标题仍用黑体 —— 中文排版里「正文楷、标题黑」是经典搭配。字体已本地化，不依赖 CDN。

粒子背景 + 磨砂玻璃

鼠标移动时粒子会被吸引连线；卡片、侧边栏、正文卡片都是半透明 + 背景模糊。也可以换成自定义图片背景，做法在下面「界面外观」一节。

排版与卡片

标题带渐变标记、表格改成圆角卡片、代码块加 mac 三点、图片支持点击放大、卡片 hover 上浮、导航滚动后变毛玻璃。

「设置」入口显眼化

右下角设置按钮改成品牌渐变胶囊 + 常驻文字 + 光环脉冲，并且页面一打开就可见（原来要滚动一段才出现，整组还是发灰的）。

新增滚动相册

一串照片横向滑动，可吸附、可拖拽、桌面端有左右箭头；换成 --marquee 就是自动滚动的跑马灯。纯 CSS + 原生 JS，没有引轮播库。

内容组件

就是下面这些。纯 HTML + class，写在 Markdown 里就能用，不需要装任何插件。

想改配色？只改 source/self/01-tokens.css 开头的 --brand-1 / --brand-2 / --brand-3 三个值，按钮、链接、渐变、标记、TOC 高亮会一起变。

文件都在哪

01-tokens.css
02-theme.css
03-article.css
04-motion.css
custom.js
文件 管什么
01-tokens.css 配色、字体、圆角、阴影、动效曲线。只想换主题色就改这一个
02-theme.css 背景、导航栏、首页卡片、侧边栏、分页、页脚、滚动条、搜索框
03-article.css 正文排版（标题 / 表格 / 代码 / 图片）+ 下面所有内容组件
04-motion.css 入场动效、hover、prefers-reduced-motion 适配
custom.js 阅读进度条、滚动入场、宽表格横向滚动、图片懒加载

这些文件是通过 _config.butterfly.yml 的 inject.head / inject.bottom 挂上去的。
改完执行 npx hexo clean ; npx hexo server 就能看到效果。
想整体关掉美化：把 inject 里那几行注释掉即可，主题配置里的 theme_color 也可以还原成原来的天蓝。

界面外观

这一节管的是「整站长什么样」，不是写文章用的组件。

背景：三种模式

① 粒子连线（当前默认）

  • 鼠标移动时粒子会被轻微吸引，连线随距离变淡
  • 由 canvas_nest 提供，脚本已本地化，不依赖外部 CDN
  • 开启后极光渐变与细网格会自动收敛，避免和粒子打架

② 自定义图片

  • 把图放进 source/img/，再改一行配置即可
  • 浅色 / 深色两套遮罩都已经配好，正文始终可读
  • 背景是固定定位，滚动时磨砂玻璃不会「晃」

background 也可以直接填颜色，例如 background: "#0f172a"。主题会根据「值是不是颜色」决定用 background-color 还是 background-image，两种写法都支持。

磨砂玻璃

正文卡片、首页卡片、侧边栏卡片、版权与相关文章都是「半透明 + 模糊」。玻璃要有东西可糊才好看，所以它和上面两种背景是配套的。

想连性能开销一起去掉：删掉 source/self/02-theme.css 里「1.5 磨砂玻璃卡片」那两行 backdrop-filter。不支持该属性的浏览器会自动退回不透明卡片。

右下角的「设置」入口

现在长什么样

品牌渐变胶囊 + 常驻「设置」文字 + 光环脉冲，页面一打开就可见（手机上自动退化成纯图标）。

首次访问提示

每个浏览器只弹一次「点右下角设置」的提示，8 秒自动消失。不想要就把 custom.js 里的 SHOW_HINT 改成 false。

条幅 —— 让图片铺满整个宽度

同一个组件有四种宽度，按需要挑：

图注不用手写：主题开了 photofigcaption，会把图片的 alt 自动渲染成下方图注。
所以这一节所有示例的说明文字，其实都写在 alt 里。

加一个 --flush 就是齐边条幅：左右一直铺到正文卡片的边缘，视觉上是一条横贯的图片带，最常用。

再加一个 --crop 就是裁切条幅：固定宽高比 + object-fit: cover，高度可控，适合做宽银幕式的题图。

满屏条幅再加 --bleed，会突破卡片铺满整个浏览器宽度。但它有个前提：DOM 里正文排在侧边栏前面，所以有侧边栏时右侧会被侧栏卡片压住。
用满屏条幅，就一定要在该文章 front-matter 里写 aside: false —— 那时是单列居中，效果才干净。

为什么不用纯 CSS 的 calc(50% - 50vw)：那是相对「最近的容器」算的，而有侧边栏时正文列并不在视口正中，算出来左右不对称。满屏条幅的偏移量由 custom.js 实测 getBoundingClientRect 得出，任何布局都准。

条幅放在文章最顶部时，方角和卡片圆角会打架，那种位置用不带 --flush 的默认条幅就好。

图标板 —— 校徽、合作方 logo

校徽这类「浅底小图」如果拉满宽度会被放大到模糊，直接丢在正文里又像一张贴歪的方图。图标板把它居中放在一条浅色板上，并把 JPEG 的灰底融进背景：

  • 图片不会被放大，只用 max-height: 88px 约束（手机 64px）
  • 深色模式下底板自动变成近白色，看起来像一枚徽章
  • 叠加 logo-plate--flush 可以让它齐边，铺满正文卡片宽度

滚动相册 —— 一串照片横向滑过去

滑动模式：横向滑动 + 滚动吸附 + 鼠标按住拖拽 + 桌面端左右箭头（触屏直接滑）。

跑马灯模式：自动匀速滚动、无缝循环、鼠标悬浮暂停，左右两端有淡出。

可调参数写在容器的 style 里：

参数 默认 说明
--gs-w 260px 每张卡宽度
--gs-h 180px 图片高度，超出部分按 cover 裁切
--gs-speed 6 跑马灯模式下每张卡走完要几秒

和主题自带的 gallery 标签的区别：那个是网格铺满、静态，适合一次看很多张；.gallery-scroll 是一行横向滚动，适合放「一串照片」，而且不占高度。

这个相册是纯 CSS + 一点点原生 JS 实现的，没有引入任何轮播库，所以不会多一个第三方依赖；prefers-reduced-motion 下跑马灯会自动停下。

主题自带的标签插件

这几个是 Butterfly 原生的，我也顺手统一了外观。

放提示、警告、要点。颜色可选 default / blue / pink / red / purple / orange / green，写法见下面代码块。

适合写「我的两年」这种按时间推进的经历，日期会自动变成胶囊标签，和上面的「步骤」互补。

一次贴多张图，hover 会放大，适合放获奖证书、赛场照片。配合「图片卡」用效果最好。

写项目介绍时我一般这样组合：封面块 开头 → 数字卡 放成果 → 正文 讲方案 → 对比栏 / 数据条 讲取舍 → 图片卡 放实物图 → 时间线 收尾。

动效说明

入场动效只作用于这些元素：首页卡片、侧边栏卡片、正文的 h2、表格、代码块、图片，以及上面提到的网格类组件。

想关掉某个元素

给它加 data-reveal="none" 属性即可。

想整体关掉

把 _config.butterfly.yml 里 inject.head 的第一行内联脚本删掉，<html> 上就不会有 .js 类，动效全部失效、内容仍然完整显示。

动效做了三层保险：不加载 JS 就不隐藏内容、浏览器不支持 IntersectionObserver 时直接全部显示、prefers-reduced-motion: reduce 时完全不动。所以「内容被藏起来看不见」这种事不会发生。

小结

✓

一句话记住

配色改 01-tokens.css，外观改 02-theme.css，写文章用 03-article.css 里的组件，动效不用管。

改完记得 npx hexo clean 再 generate —— Hexo 有缓存，这一步最容易踩坑。
